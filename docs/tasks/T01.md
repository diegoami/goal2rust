# T01 Spike: hot port routines in Rust, equal and measured (go/no-go)

- **Kind**: research spike
- **Issue**: #<n> · **Branch**: `task/T01-spike` · **Merge after**: none
- **Evidence**: [confirmed: goal2-archaeology T78d, `out/T78/family-port-v2.jsonl`, `compare-port-v2.log`]
  the Python port is equal to the original on the 75 admitted matches; [confirmed: T117 profiles,
  `notes/T117.md`] most of a match's time is machinery and a few hot routines (by calls: 0791:2BE5,
  2B51, 26D7, 2956, 045D, 0425); [confirmed: `play-speed-v1.json`] the port is 13.6 times the original
  per match.
- **Owns**: `engine/` (the crate), `bindings/`, `PROVENANCE.md`, `out/T01/**`, CI for the build.
- **Scope**: The crate skeleton (the port's memory image as a zero-copy buffer, its registers, typed
  16-bit accessors), PyO3 bindings built with maturin, and the translation of the hottest port
  routines of one subsystem (chosen from a fresh profile of E034-03's drive at the pinned
  goal2-archaeology commit), loaded by the Python dispatcher in place of their Python versions. No
  change to goal2-archaeology here: anything it needs is a request there.
- **Milestones**: M1 crate and bindings build in CI; M2 first routine equal; M3 the subsystem equal on
  the receipts; M4 paired speed receipt; M5 go/no-go written.
- **Done when**:
  1. The E034-03 straight drive with the Rust routines gives the Python port's recorded events,
     result, full memory and ordered tap sequence (`PYTHONHASHSEED=0`), and the F40 family run with
     them is `compare.py --no-screen` identical, 40 of 40.
  2. `out/T01/cpu-{python,rust}-v1.json`: the drive at the same commit with and without the Rust
     routines, run together on one quiet machine, with source hashes.
  3. `docs/go-no-go.md`: the measured speed-up of the drive and of the translated routines, the
     cost per routine of translating and proving, and a recommendation (continue routine by routine,
     change the approach, or stop) for the owner.
- **Hazards**: a per-call Python/Rust crossing that costs more than the routine (measure it); a fast
  path that skips a tap or listener the Python routine made; signedness and wrap in 16-bit arithmetic.
