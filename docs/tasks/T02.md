# T02 The machine in Rust: memory, registers, dispatcher, frames and guest calls

- **Kind**: implementation
- **Issue**: #4 · **Branch**: `task/T02-machine` · **Merge after**: T01
- **Evidence**: [confirmed: T01, `docs/go-no-go.md`, `out/T01/cpu-*-v1.json`, `crossing-v1.json`] leaf routines
  under the Python dispatcher gain 1.185x on CPython and lose on PyPy (0.76x): the cost is the per-call
  machinery (about 3.4 us a call on CPython, 6.2 M calls and returns a match). The oracle is goal2-archaeology's
  Python port (pin it in PROVENANCE.md; T01 used d3cf46a3, T78d's accepted head).
- **Owns**: `engine/` (the machine, its bindings, its tests), `out/T02/**`, `PROVENANCE.md`, CI.
- **Scope**: The go/no-go's steps 2 and 3. One Rust machine state: the memory image, the registers, the
  dispatcher (the port's `PortMachine.run`/`_dispatch`), the port frames and the guest calls with their
  returns, keeping the port's `Regs`-faithful model (stack bytes, flush runs, register effects) and its
  observable surface: io/site/listen taps in the receipts' format, the kit's write listeners and sites as
  callbacks. Exposed to Python per match event (advance to the next event, answer a decision, save/load), as
  the kit's `Match`. Unported routines run through a bridge to the Python port (proof, not speed). The seven
  routines of T01 are its first Rust routines. Not in scope: porting further subtrees (T03 onwards).
- **Milestones**: M1 the machine runs a match entirely through the bridge, equal; M2 T01's seven routines native
  in it, equal; M3 paired receipts; M4 the next-step plan (the subtree order from the profile).
- **Done when**:
  1. E034-03's straight drive through the Rust machine (the bridge for every unported routine) equals the
     Python port: events, result, full memory, stretches and the ordered taps (`PYTHONHASHSEED=0`); F40 is
     `compare.py --no-screen` identical, 40 of 40; the per-call differential is equal for the seven routines.
  2. `out/T02/cpu-*-v1.json`: the drive on the Python port (CPython and PyPy) and on the Rust machine, run
     together on a quiet machine, with source hashes.
  3. A mutant in the machine (a frame or a guest-call return) is caught, and the PR says by which check.
- **Hazards**: a frame or return that differs only in a stack byte nothing reads (T01's mutant 1: only the
  per-call differential sees it); tap order; a bridge crossing that hides a difference by re-reading state;
  measuring against CPython instead of PyPy.
