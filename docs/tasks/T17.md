## M1: seal the whole inventory before implementation runs

- Record all five bodies' inbound/outbound sites, inline helpers, argument/return
  bytes, stack/local/parent-frame writes, suspension/error and variant contracts.
- Preserve source-specific access order: positioning.local_far reads segment
  then offset through separate frame.u16/SS reads; argptr performs repeated
  mem.arg reads. Do not substitute T16's one-base contiguous-farptr pattern.
- Preserve positioning.guest's captured yielded AX, explicit live mem.reg AX on
  return paths, live stack words across calls, captured scalars versus frame/
  record rereads, aliasing, signed bytes, wrapping bases and linear subfields.
- The registered random_n supports the full word argument, unlike T16's private
  rand helper limited to n=2/5. Preserve random_core/rng_core's inline invocation,
  dead frames, seed callback ordering, register/store order, CF/DF behavior and
  argument/pointer aliases; no fake 0688 guest frame or seed-register shortcut.
- Define and seal per-body controls/case counts and the integrated proof scope.
  A discovered extra Python callee is a blocking inventory discrepancy: update
  the unstarted contract with the reason, or choose a smaller closed tree before
  freezing an epoch. Never call an open subtree complete.

## M2: resumable body proofs, then actual integrated closure

- Prove each new body against source on actual RAM captures (at least eight per
  body), at least 500 authored random/edge inputs per body and all four
  tap/listener combinations. Expand and seal counts before canonical runs; require
  positive branch/loop/site coverage, full memory/all registers/ordered observers,
  individually reached errors, direct completion, variants and pause/replay where
  guest calls can suspend. No credit for unexpected failures.
- Detect body and guest-return controls for callers; define appropriate full-state
  controls for bodies with no guest calls. Preserve all prior 23-body controls.
- Add integrated root proofs using actual new/native callees. Controlled ABI
  doubles may isolate a caller, but cannot replace the integrated closure proof.
- Instrument actual subtree frame lifetimes in proof runs to detect any default
  Python body/inline helper execution owned by the tree. Exclude shared-helper
  invocations outside the tree and intentional variant fallback. Keep instrumentation
  out of timing arms; native entry counters alone cannot prove closure.
- Push resumable milestones without running the full admitted corpus after each
  individual body. Final canonical proofs must all bind the combined fixed artifact.

## M3 / Done when

The five-body default closure is native, individual and integrated proofs pass,
and all of the following pass for one frozen combined artifact:

1. Public CPython/PyPy, Rust and GC checks; fresh complete prior23-body regression,
   new-body/integrated controls/errors/observer/closure proofs.
2. Exact ordered full drive: events, result, records, full memory and ordered IO/
   site/listener observations; positive-denial sealed lifecycle/backend attestation.
3. Strict ALL75 and exact-source F40, independent backend attestation and a fresh
   full profile confirming actual default native closure and remaining Python work.
4. Three quiet rotated simultaneous saved-T16/candidate/plain-CPython/PyPy rounds,
   original guards, every outcome retained (including regressions); show both
   saved-baseline/PyPy and candidate/PyPy ratios in the same summary. No arbitrary
   per-translation 5% floor or profile-only speed claim.
5. Closed source/binary/input/evidence ledger, preserved completed receipts and
   actual-host producer shutdown; exact-head CI, one squash PR, green main CI,
   merged-main binding verification and checkpoint.

Freeze all bound sources/binaries/inputs during canonical runs. If production
changes, preserve old receipts and create a new epoch with fresh required proofs;
do not mix artifacts or rerun selectively until a headline improves. One complete
campaign for the bundle; no reduced corpus or weaker historical Done-when.

Out of scope: broad dispatcher/bridge redesign, whole positioning module, oracle
semantic fixes, automatic model review, original data distribution, A700/ref-121/
engine owner-review/application adoption gates. Follow the roadmap's later gates;
T17 completion is neither an engine milestone nor a whole-game completion claim.
